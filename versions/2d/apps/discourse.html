    다른 순서도 가능할까?

    이 순서는 유일한 정답이 아닙니다. 아래 점검은 편집자가 지정한 연결어·지시어 의존성만 확인합니다. 점검을 통과해도 문체와 강조 효과는 별도로 토론하세요.

    읽기 실험 노트

    A와 B에 서로 다른 읽기 조건을 보존해 비교하세요. 보존본은 작업문을 바꾸어도 유지됩니다.

    지문별로 조건·순서·가설·예측·근거·관찰을 로컬 저장합니다. 새로고침해도 이 브라우저에 남습니다. 내보내기에는 보존본과 현재 작업이 모두 포함됩니다.

    탐구 안내 · 자료의 범위 · 자체 검사

    두 지문은 이 앱을 위해 쓴 창작 영어 설명·논증문입니다. 실제 학생 실험이나 측정 결과를 제시하지 않습니다. 미리 표시한 주요 담화 표지(For example, but, so, However, instead, Therefore)를 가립니다. 모든 문법적 접속사나 의미 단서를 지우는 것은 아닙니다. 이를 가리면 의미 관계를 추론하는 단서 하나만 줄어듭니다. 연결 표시를 끈다고 영어 지시어 자체가 지워지지는 않습니다.

    권장 실험: 순서를 그대로 두고 연결어만 가린 A를 보존한 다음, 연결어를 드러낸 B를 보존하세요. 다음에는 연결어 조건을 유지하고 문장 하나만 옮겨 비교하세요. 여러 조건을 동시에 바꾸면 무엇이 읽기 차이를 만들었는지 분리하기 어렵습니다.

    어구를 누르면 파랑은 지시 표현, 주황은 해당 선행 근거입니다. 연결 표시를 켜고 지시 표현을 누르세요. 영어 텍스트에는 문장 번호만 고정하며, 역할 이름은 예측 이후 편집자 주석으로 공개합니다. 새 인접 문장 사이의 관계를 임의의 NLP나 AI 점수로 판정하지 않습니다.
