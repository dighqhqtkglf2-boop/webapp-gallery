고교 핵심 · 방향을 판단하는 방법

자기장이 없는 곳과 코일이 완전히 들어간 곳에서는, 코일이 움직여도 겹친 면적이 일정합니다. 경계를 가로지를 때만 면적이 바뀝니다. 경계에 걸쳐 있어도 멈추면 선속이 변하지 않습니다.

렌츠 법칙: 유도 전류가 만드는 자기장은 원래 선속의 변화를 방해합니다. 화면 밖 자기장에 진입하면 시계 방향(화면 안 자기장 생성), 이탈하면 반시계 방향입니다. 이동 방향 또는 자기장 방향을 하나만 뒤집으면 기전력의 부호도 뒤집힙니다.

정면 관찰자 기준 반시계 방향이 +입니다. 저항을 지정하지 않았으므로 전류의 크기(A)는 계산하지 않습니다. 화살표는 저항성 폐회로의 방향만 나타내며, 자기유도는 무시합니다.

심화 · 수식, 시간, 이상화의 범위

폭 w = 0.24 m, 높이 h = 0.16 m, 자기장 폭 L = 0.80 m. 코일 중심 x에서 겹친 면적은 A = h × max[0, min(x + w/2, L) − max(x − w/2, 0)]입니다. N은 감은 수, B의 +방향은 화면 밖입니다.

쇄교 자기선속 λ = NBA (Wb), ε = −dλ/dt (V). 일정 속도 v에서 경계가 아닌 점의 ε = −NBhv [I(0 < x+w/2 < L) − I(0 < x−w/2 < L)]. 자기장 경계와 순간 정지·반전에서는 기전력이 불연속입니다. 그래프의 수직선은 이상화된 도약이며 유한한 과도현상을 뜻하지 않습니다.

재생은 실제 경과 시간(초)을 사용합니다. 드래그 기전력은 두 위치 사이 실제 경과 시간의 −Δλ/Δt, 즉 구간 평균입니다. 방향키는 1회마다 위치 0.02 m, 고정 모델시간 0.20 s를 사용하며 실제 키 입력 간격을 사용하지 않습니다. 수동 구간은 시작·끝·평균 기전력을 별도로 기록하고 정확히 해당 구간에 그립니다. 빠른 손동작은 자세히 분해하지 않습니다. 손을 떼거나 100 ms 동안 이동이 없으면 속도와 기전력을 0으로 갱신합니다. 정지 중 시간은 흘리지 않습니다. 시행은 30초 또는 이동 한계에서 멈춥니다. 30초를 넘어서는 수동 이동은 위치를 바꾸기 전에 거부하고 남은 시간은 정지 구간으로 기록합니다.

자기장·감은 수·속력 조건 변경은 현재 위치에서 새 시행(t = 0)입니다. 따라서 자기장 방향 선택은 시간 중 실제 자석 뒤집기가 아닙니다. 실제 순간 반전의 충격형 기전력은 이 모형에서 다루지 않습니다. A/B는 브라우저 메모리에만 보관되므로 새로고침 전 JSON으로 내려받으세요. 외부 자기장은 코일 높이 전체에 균일하며, 마찰·자기력에 의한 속력 변화는 제외합니다.
