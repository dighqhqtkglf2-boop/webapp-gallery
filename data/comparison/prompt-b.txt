1 생명과학 #biology '유전의 주사위': 단일 유전자 완전우성 멘델 유전 모델(연관/불완전우성 미포함). 양친 AA/Aa/aa 선택, 2x2 퍼넷 사각형(AA 부모도 배우자 A,A로), 이론 유전자형·표현형 확률 표시. 100개체 표본 생성 버튼, 개체 점 시각화와 관측비율·이론비율 막대그래프 비교. 난수 표본은 이론과 정확히 일치하지 않음 안내, Aa×Aa / AA×aa / Aa×aa 프리셋. 계산은 각 배우자 조합 확률 1/4, Aa 정규화. 표본 새로뽑기·초기화.

2 한국사 #history '조선의 시간선': 실제 조선 주요 사건 8개(1392 조선 건국,1443 훈민정음 창제,1446 훈민정음 반포,1592 임진왜란 발발,1636 병자호란 발발,1725 영조 탕평 교서 발표,1776 정조 즉위,1894 갑오개혁 시작) 카드를 위/아래 버튼과 가능하면 드래그로 재배열, 섞기/정답 확인/다시하기. 문제에는 연도 숨기기, 채점 후 정답 연도·한 줄 해설과 전체 연표. 창제와 반포 구별. 참고자료 링크 https://contents.history.go.kr/ 국사편찬위원회 우리역사넷. 개인 기록 저장 불필요.

3 지리 #geography '기후의 리듬': 가상 학습용 월별 기온/강수량 12개 편집, SVG 복합 기후그래프(좌 강수mm 막대, 우 기온°C 선), 3개 프리셋 가상 열대다우/온대계절/건조. 연평균기온, 연교차, 연강수량 실시간 계산. 정식 쾨펜 자동판정은 하지 말고 특징 관찰(월별 자료만으로 기후 원인이나 지역 단정불가), 가상자료 명시, 강수 음수 금지. 원자료 CSV 내려받기.

4 음악 #music '배음 공방': Web Audio API 기본음110~523Hz,1~8차 배음 세기0~1 슬라이더, 순음/현악형/관악형(교육용 합성 프리셋, 실제 악기 완벽재현 아님)3개, 실제 파형·스펙트럼 SVG 시각화, n차=f0*n. 재생/정지, 사용자 클릭 후 AudioContext 생성, 낮은 볼륨0.1과 짧은 fade로 안전, 과목 이동/탭숨김 때 정지. 무음 상태도 시각화 유지. 이어폰 사용시 작은 음량 안내.

5 정보 #informatics '정렬의 순간': 버블/선택/삽입 정렬, 동일 초기 배열[38,12,65,24,51,7,43,19] 막대그래프와 현재 비교/확정 원소 색 구별, 실행/일시정지/한단계/처음/속도. 비교횟수는 원소값끼리 비교할 때만 증가(루프 조건 제외), 세 알고리즘 정확한 동작 기록 배열로 구현. 알고리즘 전환시 이전 타이머 해제/초기화. 완료 오름차순. 중복값 입력 포함 사용자배열(3~16개 정수 1~99)도 지원.
