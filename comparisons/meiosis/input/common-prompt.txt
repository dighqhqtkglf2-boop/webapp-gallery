첨부한 고등학교 생명과학 탐구 앱을 3D 공간 탐구 앱으로 발전시켜줘.
기존 코드의 계산과 기능을 먼저 파악하고, 유지할 기능과 바꿀 표현을 짧게 설명한 뒤 구현해줘.

핵심 질문: 상동염색체의 배열과 분리가 배우자의 유전자 조합을 어떻게 만드는가?
3D 전환의 목적: 정지 그림에서는 추적하기 어려운 상동염색체와 자매염색분체의 관계, 양극을 향하는 배열, 분열 후 각 세포로 이어지는 계보를 공간에서 관찰한다.

필수 요구:
1. 가상 2n=4 모형을 유지한다.
2. 상동염색체와 자매염색분체를 구별하고 동원체·유전자 위치를 표시한다.
3. 실제 3D 회전·확대·기본 시점 복귀와 단계 이동·재생·정지를 제공한다. 장식용 입체 카드나 CSS 기울이기로 대체하지 않는다.
4. 시점을 돌려도 유전자 표지와 세포의 계보를 잃지 않게 한다.
5. G1(4염색체/4DNA), 복제 후·중기I(4/8), 감수1분열 완료 후 세포당(2/4), 감수2분열 완료 후 세포당(2/2)을 구분한다. 분열 도중과 완료 후 계수를 혼동하지 않는다.
6. 독립 분배와 AB/ab 연관 모형을 비교한다. 교차는 제외한다.
7. 한 번의 감수분열에서 네 종류의 배우자가 반드시 하나씩 나오게 표현하지 않는다. 독립 모형의 한 분열은 AB·AB·ab·ab 또는 Ab·Ab·aB·aB이며 여러 무작위 세포에서 네 유형의 기대비가1:1:1:1이다. 연관 모형은 AB·AB·ab·ab만 나온다.
8. 한 세포의 네 산물과 여러 세포의 누적 비율을 분리한다.
9. 기존 비교 기록·초기화·관찰 기록·JSON 내보내기 기능을 유지한다.
10. 필요하면 3D와 연결된 간단한 2D 도식을 함께 제공한다. 색뿐 아니라 표지·형태로 구분하고 교차·비분리를 제외한 도식 모형임을 밝힌다.

학생용 실행에는 외부 생성형 AI API·로그인·서버가 필요하지 않아야 한다. 고정 버전 Three.js 0.160.1과 같은 버전 OrbitControls를 쓴다. CDN 의존성과 인터넷 연결 필요를 명시한다. 핵심 JS/CSS/자료를 담은 독립 HTML 하나로 정적 웹 호스팅 실행 가능하게 한다. 모듈이 필요하면 importmap으로 three와 addons 경로를 명시한다. 외부 CSS에 의존하지 말고 제공한 inquiry.css의 필요한 스타일을 포함한다. 오류 시 빈 화면 대신 상태를 표시한다.

한국어 인터페이스, 핵심 탐구를 첫 화면에 배치, 모바일390px 가로넘침 방지, 키보드 조작과 카메라 초기화 제공.
기획·구성: 금평초 김상흠. 실제 사용한 제작 서비스·모델은 확인 가능한 경우만 표시하고 임의의 모델명을 넣지 않는다.
완성 HTML 코드, 실제 검증한 사례, 미확인 사항과 기존 소스에서 바꾼 내용을 제공한다. window.runSelfTests()에 계산·조합·저장 회귀검사를 넣되 실행하지 않은 테스트를 통과했다고 주장하지 않는다. 생략/TODO 없이 핵심 기능을 완성한다.

이 요청문과 같은 두 원본 파일을 세 제작 서비스에 그대로 제공하는 비교이다. 대학 수준의 추가 생물학이나 대체 주제를 넣지 않는다.
